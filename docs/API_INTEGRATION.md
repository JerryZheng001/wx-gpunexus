# 市场接口联调

测试服务：`https://test.chengfangtech.com`。协议以最新《小程序 API 参考》（`market-mini-program-api-reference (2).md`）为准。

## 前端接入

- 市场及首页最新信息：公开市场列表、服务端筛选、分页、总数、失败重试。列表失败不会回退演示商品。
- 三类公开详情按各自 DTO 解析，不使用私有 payload 包装。只复制页面展示字段；不展示公开响应中的联系方式、资质、用户和审核信息。
- 发布管理：Bearer JWT、本人列表/详情、按类型及状态查询、分页、编辑、提交/重新提交、售卖/需求撤回、申请下架、草稿/驳回删除。
- 发布表单及图片上传：售卖、租赁、需求三类协议；供应商名称、电话/邮箱、通用联系方式、商品数量与每台 GPU 数量分别提交；图片读取上传返回的 URL。
- 新建先创建 draft，再提交审核；ID 在 submit 前持久化。提交失败不再新建；创建超时、500 或结果不确定时要求核对本人列表。写操作不自动重试。
- 售卖 PATCH 保留原有可编辑字段；租赁私有 camelCase 先映射到创建/编辑使用的 snake_case。只读 ID、审核、认证状态和地区名称不回传。
- 上架、平台审核及续期不在客户端提供；租赁待审不提供撤回，已下架不提供删除。申请下架后以服务端状态为准，不能直接当作已下架。
- 金额字符串保持精度，支持去掉末尾零的市场卡片。租赁币种为空时不猜币种；公开租赁数值报价按原值展示。有效期设置不被当作后端自动到期保证。
- 本地真实草稿与演示草稿分开，按凭证指纹分区。Token 本身不进入草稿、请求 URL、错误信息或日志。
- 真实发布表单已补齐省市联动选择、地区草稿恢复及编辑回填。需求必选完整省市；仅提交 provinceCode/cityCode，切换省份清除旧城市，直辖市省市同码。数据来源、许可和后端抽样校验见 [省市字典来源](REGION_DATA.md)。

## 本地鉴权与启动

市场分享支持商品卡片、详情页和市场列表：微信使用原生转发按钮，详情及市场页面支持右上角菜单分享到朋友圈。商品标题包含类型、名称与报价，首张 HTTP(S) 图片作为封面，路径只携带类型与 ID；打开分享后重新读取公开详情，无需登录及列表缓存。失效详情继续显示下架提示。市场列表分享保留关键词、类型、成色及排序，接收端校验后恢复筛选并从第一页查询。H5 分享按钮复制当前站点对应链接。微信实际发送与朋友圈预览仍需开发者工具或真机验收。

市场商品收藏已接入 `POST/DELETE /api/market-mp/favorites`，两种方法都携带 JSON 请求体及 Bearer；`targetType=listings`，`targetId` 使用原始 ID 的十进制字符串，`biz` 区分 sale/lease/demand。同号商品不混淆，成功后才更新状态，写失败不自动重试。

“我的”收藏数量及列表使用 `GET /api/market-mp/favorites?type=listings&page=1&size=20`（数量查询 size=1）。按服务端统一页码加载，包含失效记录；有效卡片跳转公开详情，失效记录保留并允许取消收藏。读取失败显示错误及重试，不视为空收藏。

“我的收藏”支持关键词搜索。当前文档的收藏查询只支持 type/page/size，不支持 keyword；搜索通过同一接口按 size=30 逐页读取全部市场收藏，再对标题、型号、分类、描述、类型和编号进行不区分大小写的字面子串匹配。失效记录可按类型、编号或“失效”搜索。搜索显示匹配数量，账号收藏总数保持服务端值；清空后恢复 size=20 的普通分页。任一页读取失败均提示错误并允许重新搜索，不将部分结果当作完整搜索结果。

协议没有单条收藏状态接口，进入商品详情时按 type=listings、size=30 逐页查询，找到目标或遍历完后才确定收藏状态。账号收藏只在内存中缓存，凭证变化会重置，过时请求不能覆盖新的账号状态。行情、资讯及店铺关注仍沿用演示逻辑，不将演示 ID 上传为真实收藏。

临时测试 Token 保存于被忽略的 `.env.local`，格式：

```dotenv
MARKET_API_TEST_TOKEN=<临时 JWT>
```

文件权限为 0600，不提交。替换 Token 后重启开发服务。

需要临时 Token 的微信联调必须使用 `npm run dev:weapp`。`npm run build:weapp` 会生成不带测试凭证的正式产物，覆盖 `dist/` 后模拟器的私有接口会要求登录。当前已改回本地开发构建，并开启轮询监听以避免文件监听数量限制。

```bash
npm run dev:h5
npm run dev:weapp
npm run check:api
```

H5 开发服务通过 `/api` 代理访问测试站，移除浏览器 Origin，并仅对 provider 请求及 `/api/market-mp/favorites` 附临时 Bearer Token；Token 不打进 H5 页面。微信 watch 开发构建使用仅在本地开发产物中生效的凭证。正式构建不包含临时 Token，使用运行时登录凭证 `suanlishi:access-token`，登录接入尚需独立协议。

已检查微信/H5 生产产物均不含临时 Token。`dist/`、`dist-h5/`、`.env.local`、`output/` 均不纳入版本管理。

默认 API 根地址可用命令环境变量覆盖，地址不带 `/api` 后缀：

```bash
TARO_APP_API_BASE_URL=https://your-api.example.com npm run dev:weapp
TARO_APP_API_BASE_URL= npm run dev:h5  # 显式选择本地演示模式
```

H5 生产服务需配置 CORS；微信需配置 request 及图片合法域名。`npm run check:api` 仅发 GET，不创建、提交、审核或删除数据；部分协议尚未部署时返回非零。

微信本地联调已在被忽略的 `project.private.config.json` 中设定 `setting.urlCheck=false`，避免未配置测试域名时被模拟器拦截。已打开的工具若未载入该设置，需重新打开项目；正式预览与发布仍需配置合法域名。请求失败会区分域名拦截、超时及 HTTPS 证书错误，且不回显原始异常中的 URL 或凭证。市场首屏失败后，重新进入页面会重试读取。
